# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

It is adopted by reference rather than copied, so that it cannot drift from the
canonical text over time.

## In short

Be decent. Argue about the work, not the person. Assume the other side has a
reason you have not heard yet — and ask for it before concluding they are wrong.

## Enforcement

Reports go to the maintainer through GitHub (a private security advisory on this
repository is the most private channel available here). Reports are handled
confidentially. The maintainer decides, explains the decision to the person who
reported, and applies the consequences the Covenant provides for.
